Grants Intake Management System

Working SSP · Agency FISMA — NIST SP 800-53 Rev. 5 · Moderate baseline

1.1 System Purpose

The Grants Intake Management System (GIMS) supports the agency's discretionary grant application lifecycle. The system receives applications, routes submissions to program reviewers, records review decisions, and produces award recommendation packages.

1.2 System Ownership

The Office of Grants Management is the system owner. The Office of the Chief Information Officer operates the hosting environment and provides identity, network, logging, vulnerability management, and incident response services.

1.3 Operational Status

GIMS is in pre-production implementation. The authorization boundary and production hosting architecture have been confirmed. Production operational procedures are being finalized.

1.4 System Description

GIMS is a browser-based application deployed in an agency-owned AWS commercial environment. The boundary includes the application service, managed relational database, object storage, agency identity integration, centralized logging integration, and supporting network controls.
